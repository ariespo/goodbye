## 共用入口与播放

- `conclusion-transition.ts` 的普通桥接按已确认材料衔接，不要求嫌疑人突然在场。相同路线的拒绝选项不再共用“已经放下/承认”的动作；末句接后果，不让已经作出选择的人再选一次。
- `cycleLoop.ts` 的 STAY/TRUE 在进入固定文本前播放记忆桥接；旧选项文字仍可识别，计数、路线保留与重置规则未改。前两次留下的日终原因也明确是在回忆。
- `ending-presentation.ts` 为 17 个内置 ID 提供简短层次提示，正文保留自然的进入、退出和责任说明。标题在黑底先出现，再切结局背景；收藏预览和正文加载失败的简介回退使用同一转换器。英文/中文指令脚本均保留场景变化。
- `EndingPlayer.tsx` 不再在每个结局前声称“时间没有继续倒退”，也不把收录完成宣告成全部世界事实。新提示不修改变量、事实或结局资格。
- `DialogueBox.tsx` 在结局正文未播完时允许正常打字、点击、键盘与自动推进；转场动画和正文结束后的菜单仍阻止底层推进与回看。解决原本把“结局面板可见”一律当弹窗、导致正文锁死的问题。
- `conclusionFlow.ts` 原子提交未读桥接与待播结局，再等待持久化，防止慢保存时先依据上一幕的完成状态触发结局；返回后的异步动作不再覆盖已安装的桥接。
- 逐一看过 5 张原结局背景：TRUE 明写 9:01，STAY/LOOP 明写 9:00；F-1 有文穗在站内对视，C-1 有诊室中的文穗幽影。它们不能仅靠层次标签消除图文冲突。未生成或编辑图片，原文件与资产 ID 留存；默认 C-1/F-1/LOOP 改用已有黑底，STAY/TRUE 改用已有 `home` 空屋图（核对无人物、无钟）。资产目录描述标为旧版画面。
- `gameStore.ts` 同步内置简介、两个已过时的显示标题及上述背景选择；17 个收藏 ID、truthType、条件、顺序和已收录判断均保持。
