## 一、核心诡计：「还原妹妹的秘密一日」

### 表层叙事（玩家初始认知）

文穗谎称去上学，实际上出门办"秘密的事"。暴雨封锁了贵阳老城区，玩家无法离开街区。当天下午，玩家得知文穗死了。

玩家陷入时间轮回，每次回到当天早上，试图通过不同行动阻止她的死亡——但前三轮机制上无法拯救。

### 第一层：死因不固定

每次轮回中文穗的死亡方式可能不同（坠楼/头部撞击/窒息），取决于玩家上一轮的调查方向。这不是随机，而是**三条真相路线的暗示在分化**。

### 第二层：核心不是"谁杀了她"，而是"她今天做了什么"

文穗当天的秘密行程是整个谜题的骨架。玩家通过逐步还原她的行程站点（中学→便利店→废弃水塔→黔灵山脚步道→学姐楼附近→分歧点），才能理解她为什么会被杀、谁有机会杀她。

### 第三层：三条真相路线

根据累积的怀疑度，玩家最终锁定三条互斥的真相之一：

| 路线 | 真凶 | 核心机制 |
|------|------|---------|
| A · 阳极教献祭 | 独居老头周德明 | 邪教献祭夺寿，文穗因孤儿院"至阳之地"背景被盯上 |
| B · 侦探失手 | 侦探A赵刚（B林静掩盖） | 受雇于生父的侦探强行约谈，反抗中失手致死 |
| C · 玩家解离 | 玩家自己 | 前夜因控制欲爆发掐死文穗，解离后遗忘，轮回=创伤重演 |

每条路线都有独立的、自洽的证据链。学姐沈灯织始终不是凶手，但她是"知情观察者"。

### 设计原则

- **小细节逐步暴露**：不要开场就写死任何角色的真面目。玩家通过调查、对话、线索拼凑逐步接近真相。
- **误导与红鲱鱼**：便利店员和体育老师是前期显眼嫌疑人，但在 25 怀疑度时被排除。侦探A是"最强的直觉嫌疑人"，可成真凶也可是红鲱鱼。
- **学姐的"知情不阻"**：沈灯织察觉文穗的困境和玩家的控制欲，但不主动干预。她在等玩家"变成和她一样的孤独者"。

## 二、谜题系统设计

### 谜题1：文穗行程还原（推理核心）

**机制**：玩家在每次轮回中访问文穗经过的站点，通过物理痕迹、NPC 证词、监控片段逐步拼凑她的行程时间线。

**谜面**：文穗当天去了哪？每个时段在做什么？她为什么谎称上学？

**关键站点与可还原信息**：

| 站点 | 物理痕迹 | NPC 证词 | 监控 |
|------|---------|---------|------|
| 中学（未进） | 请假条 | 门卫老张："请假电话是男的打的" | 无 |
| 便利店 | 收银小票（07:30） | 陈慧慧："她手背有伤，买了创可贴" | 片段（常坏） |
| 废弃水塔 | 笔记本、刻痕、零食包装 | 晨练大爷："小姑娘急匆匆地走" | 无 |
| 黔灵山脚步道 | 脚印（被雨冲） | 晨练大爷："后面跟着寸头男人" | 无 |
| 学姐楼附近 | 无 | 星巴克店长："她站了10分钟，像找人" | 商住楼监控（较好） |
| 死亡地点 | 视路线而定 | 视路线而定 | 视路线而定 |

**解谜奖励**：完整还原行程 → 理解文穗的动机（调查身世/躲避跟踪/逃避骚扰），从而理解"谁有杀机"。

### 谜题2：怀疑度推理

**机制**：玩家对每个角色（独居老头、侦探A/B、便利店员、体育老师、学姐、玩家自己）累积怀疑度（0–50）。

**关键设计**：
- 0–25：排除或烟雾弹揭发
- 26–49：重点嫌疑人
- 50：锁定凶手，进入该角色真相路线

**谜面**：谁是凶手？

**关键线索的歧义性**：同一条线索可能指向不同的人。例如"请假电话是男的打的"——可能是文穗生父、侦探、甚至玩家自己。玩家需要通过多轮收集交叉验证。

### 谜题3：文穗的秘密笔记

**机制**：在废弃水塔中可发现文穗的笔记本，内容随轮回次数递进解锁。

| 轮次 | 可阅读内容 | 关键信息 |
|------|-----------|---------|
| 第2轮 | 前几页 | 孤儿院地址、院长名字、"我想知道自己从哪来" |
| 第3轮 | 中间页 | "有人一直在跟着我"、"体育课不想去"、"陈哥人好但看我的眼神有时候怪怪的" |
| 第4轮 | 后几页 | "姐姐（灯织）说我像小松鼠。可笼子是谁的笼子？" |
| 第5轮（玩家线） | 撕掉的最后一页碎片 | "如果有一天我出了什么事……是他/她不是故意的……" |

**解谜奖励**：理解文穗对所有人的真实评价，以及她对自己处境的清醒认知。

### 谜题4：玩家自身的异常（玩家线专属）

**机制**：在社区医院、自己家中可发现与玩家精神状态相关的证据。

| 线索 | 表面 | 深层 |
|------|------|------|
| 药瓶 | "感冒药" | 利培酮（抗精神病药物），标签被撕掉一半 |
| 请假电话记录 | "谁打的？" | 来自玩家自己的手机 |
| 指甲缝的组织 | "什么时候蹭的？" | 文穗挣扎时的皮肤组织 |
| 文穗的碎信 | "写了一半的作业" | 文穗试图写给玩家但没完成的告别信 |
| 记忆碎片/既视感 | "似曾相识" | 前夜跟踪文穗的真实记忆被解离重组 |

### 谜题5：学姐的"知情不阻"边界

**机制**：沈灯织会在不同轮回中透露不同层级的信息，取决于玩家与她的好感度。

| 好感度 | 灯织透露的信息 |
|--------|---------------|
| <40 | "你的小松鼠最近好像很忙。" |
| 40–60 | "她好像在躲什么人。你注意到了吗？" |
| 60–80 | "有人来找过她。不是好人。"（指侦探） |
| 80+ | "你有没有想过，问题可能不在外面？"（暗示玩家线） |

**设计意图**：学姐始终不直接说出真相，但提供足够的信息让聪明的玩家推断。她的"不阻"不是冷漠，而是一种扭曲的期待——她希望玩家失去文穗后能理解她的孤独。

## 三、角色与设计功能

### 角色一览

| 角色 | 姓名 | 定位 | 怀疑度可达 | 设计功能 |
|------|------|------|-----------|---------|
| 妹妹 | 文穗 | 核心人物 | — | 行程还原的对象；她的秘密驱动整个故事 |
| 学姐 | 沈灯织 | 双面信息节点 | 永不可到50 | 知情观察者+孤独共鸣；提供分阶段信息 |
| 便利店员 | 陈慧慧 | 烟雾弹 | 最高25 | 不善社交造成的过度关注感；前期显眼嫌疑人 |
| 独居老头 | 周德明 | 可锁定凶手 | 可到50 | 阳极教献祭线；表面最无害实际最危险 |
| 体育老师 | 刘仁光 | 烟雾弹 | 最高25 | 性骚扰但非致死主因；推动文穗行为 |
| 侦探A（明） | 赵刚（化名） | 可锁定凶手线 | 可到50 | 受雇侦探失手线；最强直觉嫌疑人 |
| 侦探B（暗） | 林静（化名） | 统筹者 | 伴随A出现 | A的上级；冷静掩盖；小动物直觉无效 |
| 玩家 | {{user}} | 可锁定凶手线 | 可到50 | 控制欲+解离；前夜凶手；轮回=创伤重演 |

### 角色深化要点

**文穗**：
- "等价交换"口头禅的本质：怕自己不值得被无条件爱
- 最近变化：因彻底信任玩家而开始调皮/任性/隐瞒——这是自我保护的正面信号，却被控制欲型玩家误读为"背叛"
- 小动物直觉：能感知谁的好是真的、谁在"演"——对学姐感觉"很好，但像在看别的东西"
- 死亡时表现：第一轮回后玩家得知死讯；死因/地点随真相路线变化

**沈灯织**：
- "小松鼠"双关：表面宠称；深层暗示她隐约感到玩家对文穗的控制欲
- 核心矛盾：羡慕文穗能与玩家共同生活。不是想取代文穗，而是想要"那种关系"——被完全接纳、完全信任
- 期待：玩家失去文穗后会与她一样"孤独"——智识共鸣式的真正关系

**玩家**：
- 表面温厚监护人；深层控制欲极强；解离倾向；恐惧被抛弃
- 背景：父母离异式情感匮乏（钱在情无）；领养境遇相似、乖巧的文穗，以掌控关系填补孤独
- 药瓶：表面"感冒药"；心理线实为抗精神病类（利培酮）
- 呈现原则：小细节逐步暴露，不要开场就写死控制狂本相

## 四、嫌疑结构与误导

### 玩家早期直觉排序

```
侦探A ≫ 体育老师 > 便利店员 > 独居老头 > 学姐
```

### 实际设计

| 角色 | 设计功能 |
|------|---------|
| 侦探A/B | 强红鲱鱼；推动文穗行为；可成真凶路线之一 |
| 学姐 | 动机外观可疑，但永不可锁凶 |
| 体育老师/店员 | 前期显眼嫌疑人→25揭发烟雾弹 |
| 老头/侦探/玩家 | 可到达50的真凶路线 |

### 25 怀疑度揭发

- **便利店员陈慧慧**：不善与人交往的热情被误读为越界关注；属烟雾弹但非杀机
- **体育老师刘仁光**：有色胆无色心——恶心但未构成致死主因

## 六、叙事节奏设计

### 第1轮：「她怎么了？」

- **核心体验**：建立基本认知——文穗没去学校、她有秘密、她死了、这是轮回
- **可发现站点**：中学、便利店
- **情绪基调**：困惑、急迫
- **设计重点**：烟雾弹启动（便利店员、体育老师）；时间锚（暴雨预警）

### 第2轮：「她在调查什么？」

- **核心体验**：从"谁杀了文穗"扩展到"文穗在做什么"
- **可发现站点**：废弃水塔、黔灵山脚步道
- **情绪基调**：困惑深化、不安
- **设计重点**：文穗调查身世线揭示；侦探A间接出场（晨练大爷目击）；自疑度开始积累（请假电话是男的打的）

### 第3轮：「她在躲谁？」

- **核心体验**：意识到"无法拯救"——前三轮的无力感
- **可发现站点**：学姐楼附近、死亡地点初步
- **情绪基调**：无力、恐惧
- **设计重点**：学姐"知情"特质启动；侦探A/B从间接变为可调查；死亡地点开始可定位；自疑度持续积累

### 第4轮：强制复盘

- **核心体验**：从漫无目的探索转为有方向的调查
- **机制**：强制复盘事件——LLM按当前怀疑度生成嫌疑评估报告；25以下排除、26–49标记重点
- **情绪基调**：聚焦、紧迫
- **设计重点**：烟雾弹角色正式排除；引导玩家聚焦重点嫌疑对象

### 第5轮+：锁凶与真相

- **核心体验**：真相揭露与最终抉择
- **机制**：怀疑度达50的角色触发锁定事件
- **情绪基调**：震惊→沉痛→抉择
- **设计重点**：三条真相路线的独立演出；不同结局分支

### 终幕：告别

- 三条路线各自的结局分支
- 共同的情感核心：无论凶手是谁，玩家都要面对"失去文穗"这一事实
- 最后场景：暴雨停歇，玩家独自面对空房间

## 七、与旧版设计的对照

| 旧版（时间锚点诅咒） | 重构版（还原秘密一日） |
|---|---|
| 核心诡计："不存在的外部凶手" + 轮回本身是凶手 | 核心诡计：还原文穗行程 + 多嫌疑人怀疑度锁凶 |
| 文穂13岁，繁体混用 | 文穗14岁，简体统一 |
| 时间锚点/诅咒/能量抽取 | 无超自然元素（老头线有邪教但非超自然） |
| 死亡时间固定=醒来+8小时，越来越早 | 死因/地点随真相路线变化，非时间规律 |
| 4+1种真相（自刃者/梦觉/深渊/等价交换/观测者） | 3种真相（老头献祭/侦探失手/玩家解离） |
| 时坂朔是关键角色 | 时坂朔已删除 |
| 锚点物品有超自然属性（挂钟倒转=时间消耗） | 物品变化是心理暗示/解离症状（玩家线）或环境暗示 |
| 虐绞狂是核心诡计要素 | 虐绞狂仅表层悬疑/误导 |
| 开场"记忆复苏" | 开场：文穗已出门，玩家寻找她 |
