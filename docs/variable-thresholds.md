# 变量阈值表

**用途**：定义所有游戏变量的数值区间、初始值、增减触发条件和阈值效果。供 LLM prompt 组装、结局判定和系统行为使用。

---

## 一、变量总览

| 变量 | 类型 | 区间 | 初始值 | 跨轮回 | 说明 |
|------|------|------|--------|--------|------|
| `cycleCount` | number | 0+ | 0 | ✅ 保留 | 轮回计数器 |
| `suspicion.*` | object | 0–50 | 各异 | ✅ 保留 | 按角色怀疑度 |
| `affinity.*` | object | 0–100 | 各异 | ✅ 保留 | 按角色好感度 |
| `investigation` | number | 0–100 | 0 | ✅ 保留 | 行程还原进度 |
| `stamina` | number | 0–120 | 100 | ❌ 重置满 | 体力 |
| `sanity` | number | 0–100 | 70 | ❌ 继承-5 | 理智 |
| `unlockedClues` | string[] | — | [] | ✅ 保留 | 已收集线索 |
| `organizedClues` | string[] | — | [] | ✅ 保留 | 已整理线索 |
| `endingsSeen` | string[] | — | [] | ✅ 保留 | 已见结局 |
| `lockedRoute` | enum | A/B/C/null | null | ✅ 保留 | 锁定路线 |

### 2.3 25 揭发事件（烟雾弹排除）

当便利店员或体育老师怀疑度达到 25 时，触发强制揭发事件：

**便利店员揭发**：
- 陈慧慧主动说："你是不是觉得我对文穗太好了？……我只是，不太会和人说话。她每次来，我都怕自己显得太冷淡。"
- 怀疑度锁定在 25，标记为"排除"。
- 此后调查便利店不再增加怀疑度。

**体育老师揭发**：
- 通过同学小禾或门卫得知：刘仁光被投诉过"肢体接触不当"，学校给了警告处分。
- 怀疑度锁定在 25，标记为"排除"。
- 此后调查中学不再增加体育老师的怀疑度。

### 2.4 50 锁定事件

当老头/侦探A/侦探B/自疑度任一达到 50 时：
- 其他角色的怀疑度**冻结**（不再增减）
- 触发该角色的锁定演出
- `lockedRoute` 设为对应路线
- 游戏进入"抉择"模式

## 五、体力（stamina）详细规则

### 5.1 基础参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 初始值 | 100 | 每轮重置 |
| 第4轮后上限 | 120 | 复盘后解锁 |
| 每轮自然消耗 | 0 | 不随时间自然消耗 |

### 5.2 消耗表

| 行为 | 体力消耗 | 时间消耗 |
|------|---------|---------|
| 站点间移动 | 5–15 | 10–20分钟 |
| 观察（单次） | 0 | 0 |
| 调查（单次） | 5–25 | 10–45分钟 |
| 行动（单次） | 5–25 | 10–45分钟 |
| 与NPC对话 | 0–5 | 5–15分钟 |
| 体力归零昏睡 | — | 1–3小时 |

### 5.3 体力归零机制

- 体力归零 → 触发昏睡事件
- **昏睡演出**：画面渐暗，暴雨声变大，文字提示"你突然感到一阵强烈的困意……"
- **昏睡时长**：1–3小时游戏内时间（随机或根据剧情需要）
- **醒来后**：时间已大幅推进，可能已到死亡时段（16:00–17:00）
- **剧情解释**：感冒药副作用 + 解离发作（双重）

### 5.4 体力恢复

| 方式 | 恢复量 | 条件 |
|------|--------|------|
| 休息（原地） | +20 | 消耗30分钟 |
| 喝水/吃东西 | +10 | 需要有对应物品 |
| 轮回重置 | 满 | 每轮开始 |

## 七、跨轮回变量继承规则

### 保留的变量

```
cycleCount       → 保留并 +1
suspicion.*      → 保留（25揭发的角色冻结在25）
affinity.*       → 保留
investigation    → 保留
unlockedClues    → 保留
organizedClues   → 保留
endingsSeen      → 保留
lockedRoute      → 保留
```

### 重置/衰减的变量

```
stamina          → 重置为100（第4轮后120）
sanity           → 上轮值 - 5（不低于20）
当前场景          → 重置为 bedroom1
当前时间          → 重置为 07:30
当前角色          → 重置为 旁白/玩家
```

## 八、结局判定条件

### 8.1 路线锁定判定

```
IF suspicion.oldMan >= 50:
    lockedRoute = 'A'   // 阳极献祭

ELSE IF suspicion.detectiveA >= 50 OR suspicion.detectiveB >= 50:
    lockedRoute = 'B'   // 失手掩盖

ELSE IF suspicion.self >= 50:
    lockedRoute = 'C'   // 解离重演

ELSE IF cycleCount >= 7 AND no route locked:
    // 兜底：触发"困在轮回中"结局
    lockedRoute = 'LOOP'
```

### 8.2 结局分支判定

每条路线锁定后，根据玩家在"抉择"阶段的选择决定具体结局：

**路线 A（老头线）**：
- A-1 报警 → 法律正义结局
- A-2 私了 → 灰色结局

**路线 B（侦探线）**：
- B-1 报警 → 法律正义结局
- B-2 接受生父补偿 → 灰色妥协结局

**路线 C（玩家线）**：
- C-1 接受 → 灰暗但清醒的结局
- C-2 否认 → 永恒自我囚禁结局

**兜底（LOOP）**：
- 玩家困在无限轮回中，无法锁凶

### 8.3 二周目解锁

- 通关任意一条路线后，`endingsSeen` 记录该结局
- 二周目保留 `unlockedClues` 和 `suspicion`（加速进入第4轮）
- 通关两条路线后，第三条路线解锁隐藏线索（之前不可见的证据）
- 通关三条路线后，解锁"灯织视角"模式（可选）
