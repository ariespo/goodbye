# 暴雨预警与 NPC 对话树

**用途**：定义暴雨预警作为时间锚的机制，以及10个地点固定 NPC 的对话树设计。

---

## 一、暴雨预警作为时间锚

### 1.1 暴雨预警的核心功能

重构后取消了庆功宴设定。暴雨本身接管了时间锚的功能：

| 功能 | 说明 | 机制表现 |
|------|------|---------|
| **时间锚** | 手机推送暴雨橙色预警，预计18时前后雨势最强 | 09:00 推送预警，18:00 为暴雨高峰 |
| **误导** | 玩家可能以为暴雨本身是天灾掩护/与死亡有因果关系 | 增加不安感，但暴雨只是环境因素 |
| **玩家线证据** | 玩家手机里的天气截图可能与其他人的记录不一致（解离产物的细节矛盾） | 自疑度+5~10 |
| **行动限制** | 暴雨封路限制玩家行动范围在街区内 | 机制上限制地图边界 |
| **文穗行为线索** | 文穗当天路过学姐楼附近但没进去——她在犹豫是否向灯织求助 | 第3轮可发现 |

### 1.2 暴雨预警在各轮次中的表现

| 轮次 | 预警相关事件 | 设计意图 |
|------|-------------|---------|
| 第1轮 | 09:00 手机推送暴雨橙色预警 | 建立时间锚 |
| 第2轮 | 预警内容微变，升级为红色预警 | 紧迫感升级 |
| 第3轮 | 玩家可发现文穗在学姐楼附近徘徊（想求助但没进去） | 揭示文穗的犹豫 |
| 第4轮 | 暴雨高峰时段文穗已死，预警变成背景声 | 无力感 |
| 第5轮+ | 灯织好感≥80时说“你有没有想过，那天的雨，你真的淋过吗” | 暗示玩家线记忆矛盾 |

### 1.3 玩家线中的天气矛盾

在路线 C（玩家解离线）中，天气记录是一个关键误导点：
- 玩家手机里的暴雨截图显示“18时最强”
- 但社区医院的值班医生/其他NPC提到的暴雨高峰时间不同
- 这种细节矛盾是解离产物的标志——玩家的记忆在重组时出现了时间错位
- 发现“天气记录不一致” → 自疑度+10

### 1.4 灯织与暴雨预警的交互

取消了庆功宴后，灯织的社交功能通过以下方式实现：

| 玩家行为 | 好感度影响 | 效果 |
|---------|----------|------|
| 去学姐楼找灯织聊天 | 灯织+5~10 | 但消耗时间/体力 |
| 拒绝灯织的关心 | 灯织-5 | “你不用管我” |
| 忽略灯织的消息 | 灯织-3 | 灯织会再发一条 |
| 在灯织面前提到文穗的好 | 灯织+5 | 灯织羡慕但欣赏 |
| 在灯织面前贬低文穗 | 灯织-10 | 灯织会冷下来 |

## 二、NPC 对话树设计

### 设计原则

1. **每地有 NPC**：10个地点中，8个有固定 NPC（废弃水塔和观景台无 NPC）
2. **渐进式对话**：NPC 的对话随轮回次数递进，不是一次说完
3. **信息分层**：每个 NPC 的对话分三层——表层闲聊、中层线索、深层秘密
4. **好感度/怀疑度联动**：部分 NPC 的深层对话需要满足条件才解锁

### 2.1 玩家公寓 — 楼下小卖部老板娘

| 轮次 | 对话内容 | 解锁条件 |
|------|---------|---------|
| 第1轮 | "哟，今天起这么早。你家那闺女出门更早，我看她往老街那边走的。上学不是往那边吧？" | 无 |
| 第2轮 | "你最近脸色不太好。是不是没睡好？楼下那个男的又来了——你说是不是跟踪狂啊？" | cycleCount≥1 |
| 第3轮 | "你妹妹最近常往外跑，我看好几次了。你当哥哥/姐姐的管管。" | cycleCount≥2 |
| 第4轮+ | "你是不是该去看看医生？我看你最近眼神发直，跟丢了魂似的。" | cycleCount≥3 |
| 深层 | "那男的寸头，站楼下好几天了。我问他找谁，他说等人。我看不像好人。" | 怀疑度·侦探A≥15 |

| 深层 | "有一次我好像看到沈小姐带那小姑娘上楼了。两个人聊了很久。小姑娘出来的时候眼睛红红的。" | 疑灯织≥20 |

### 2.10 沈灯织（学姐）— 非地点绑定 NPC

灯织不绑定特定地点，她可在以下场景出现：
- 学姐楼附近/内部
- 玩家公寓阳台可见
- 微信消息

| 轮次 | 触发场景 | 对话内容 | 好感度要求 |
|------|---------|---------|-----------|
| 第1轮 | 微信消息 | “今天雨大，别出门了。要是文穗没去上课，让她来我这边坐坐。” | 无 |
| 第2轮 | 微信消息 | “你还好吗？昨天看你脸色不太好。” | 无 |
| 第3轮 | 学姐楼/阳台 | "你的小松鼠最近好像很忙。……不过，笼子太小的确会这样。" | 无 |
| 第4轮 | 学姐楼 | "她好像在躲什么人。你注意到了吗？" | ≥40 |
| 第4轮 | 学姐楼（深） | "有人来找过她。不是好人。" | ≥60 |
| 第5轮+ | 学姐楼（最深） | "你有没有想过，问题可能不在外面？" | ≥80 |
| 结局后 | 阳台/微信 | “你还好吗。” | 通关后 |

### 灯织的特殊台词设计

灯织的台词始终带有"双关"特质——表面是关心/社交，深层是暗示/期待：

| 台词 | 表面含义 | 深层含义 |
|------|---------|---------|
| "你的小松鼠最近好像很忙" | 关心文穗 | "小松鼠"=被关在笼子里的=被你控制的 |
| "笼子太小的确会这样" | 感叹 | 你对文穗的控制欲，她察觉了 |
| "她好像在躲什么人" | 提供信息 | 她知道文穗在躲侦探，但没说全 |
| “你还好吗” | 社交安慰 | 她还在等——等你变成和她一样的人 |
| "你做了和文穗一样的事" | (A-2结局) | 不让自己被看见=用沉默交换——你和文穗的"等价交换"一样 |

## 三、NPC 对话的 LLM 指令扩展

### 固定对话指令

```
条件对话|<角色ID>|<条件表达式>|<文本>
```

示例：
```
条件对话|门卫老张|cycleCount>=1 AND suspicion.self>=5|"对了，那个请假电话……是个男的打的。我当时就觉得奇怪。"
条件对话|晨练大爷|cycleCount>=2 AND suspicion.detectiveA>=10|"后面跟着个寸头男人，距离有点近。"
```

### 对话解锁规则

NPC 的深层对话需要满足以下条件之一才在 LLM 的可选输出中出现：

1. **轮次条件**：`cycleCount >= N`
2. **怀疑度条件**：`suspicion.<角色> >= N`
3. **好感度条件**：`affinity.<角色> >= N`
4. **进度条件**：`investigation >= N`
5. **组合条件**：以上条件的 AND 组合

不满足条件的对话不会出现，确保信息是渐进式释放的。
