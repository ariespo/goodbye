# 结局分支设计

**用途**：定义结局体系的三层结构（锁凶层 / 解释层 / 元层）、各结局的触发条件与文本方向。供结局判定系统和结局文本文件使用。

---

## 一、三层结构总览

```
锁凶层（谁是凶手）      A 老头 / B 侦探 / C 玩家 / NONE 无凶手 / FAKE 假死
解释层（这一切是什么）   REAL 现实 / CULT 邪神（叠加于A） / PSYCH 精神疾病（叠加于C）
元层（要不要离开）      STAY 无限轮回（软结局） → TRUE 告别（真结局）
```

- **锁凶层**由怀疑度/证据链锁定，`lockedRoute` 取值 `'A' | 'B' | 'C' | 'NONE' | 'FAKE' | null`
- **解释层**是对已锁路线的深层重释，`overlay` 取值 `'CULT' | 'PSYCH' | null`。CULT 只能叠加在 A 线上，PSYCH 只能叠加在 C 线上；不满足叠加条件时按 REAL（现实）解释走原结局
- **元层**跨越所有路线，是"对轮回本身的态度"。STAY 可反悔，TRUE 终结游戏

### 结局总表

| 层 | 路线 | 结局 | 文件名 | 类型 |
|----|------|------|--------|------|
| 锁凶·A | 阳极献祭（老头） | A-1 报警·审判 / A-2 私了·了断 | `A-1.txt` `A-2.txt` | 硬结局 |
| 锁凶·B | 失手掩盖（侦探） | B-1 报警·揭露 / B-2 接受·妥协 | `B-1.txt` `B-2.txt` | 硬结局 |
| 锁凶·C | 解离重演（玩家） | C-1 接受·清醒 / C-2 否认·囚禁 | `C-1.txt` `C-2.txt` | 硬结局 |
| 锁凶·NONE | 漫长的告别（无凶手） | N-1 读信·放手 / N-2 拒信·回环 | `N-1.txt` `N-2.txt` | 硬/软 |
| 锁凶·FAKE | 金蝉（假死） | F-1 放她走 / F-2 追到底 | `F-1.txt` `F-2.txt` | 硬结局 |
| 解释·CULT | 阳极真神（A叠加） | X-1 毁坛·渎神 / X-2 献祭·续命 | `X-1.txt` `X-2.txt` | 硬结局 |
| 解释·PSYCH | 内室（C叠加） | P-1 醒来 / P-2 沉入 | `P-1.txt` `P-2.txt` | 硬结局 |
| 元·STAY | 无限轮回 | STAY 早安·永远 | `STAY.txt` | 软结局（可反悔） |
| 元·TRUE | 告别 | TRUE 九点零一分 | `TRUE.txt` | 真结局 |
| 兜底 | 困局 | LOOP 遗忘 | `LOOP.txt` | 软结局 |

**旧结局文件处理**：`D-1.txt` / `D-3.txt` / `E.txt` 删除（旧"等价交换/观测者"体系，已无对应路线）。

## 二、路线 A：阳极献祭 — 独居老头线

### 锁定后演出

玩家在老头楼内室发现祭坛和阳极地名单，老头出现。揭示完整真相：文穗因孤儿院"至阳之地"背景被老头盯上，以避雨诱上楼，仪式后推下楼伪装坠亡。

### A-1：报警·审判

**触发**：玩家选择"报警，让法律处理"

**剧情走向**：
- 玩家带着证据（祭坛照片、名单）离开老头楼
- 暴雨开始减弱。玩家在社区医院/派出所报案
- 老头被逮捕。阳极教的荒诞在法律框架下显得更加可怖
- 文穗的死因被重新定性为"他杀"，而非"意外坠亡"
- 玩家站在文穗的墓前/空房间前

**结局文本方向**：
- 法律正义，但正义无法让文穗回来
- 玩家终于理解文穗"等价交换"的另一面——有些事不是交换，是失去
- 暴雨停了，但空房间的安静比雨声更响

### A-2：私了·了断

**触发**：玩家选择"自己处理，不报警"

**剧情走向**：
- 玩家与老头对峙。在暴雨中，玩家做了什么——是推他下楼？是质问后离开？留白处理
- 老头的死/认罪被暴雨冲刷
- 玩家没有得到"法律正义"的干净感，只有灰色了断
- 灯织在事后出现："你做了和文穗一样的事——不让自己被看见。"

**结局文本方向**：
- 灰色结局。暴力无法带来正义，只是填补了空洞
- 玩家用暴力了断，却发现自己和"控制欲"的距离比想象中近
- 灯织的台词暗示她看到了玩家身上的某种"变化"

## 三、路线 B：失手掩盖 — 侦探线

### 锁定后演出

玩家在侦探小旅馆/废弃水塔附近找到决定性证据（赵刚抓痕、纤维匹配、通讯记录）。揭示完整真相：侦探A强行约谈→文穗反抗→失手致死→B协助掩盖伪装坠亡。

### B-1：报警·揭露

**触发**：玩家选择"报警，揭露一切"

**剧情走向**：
- 玩家将证据提交给警方
- 侦探A/B被逮捕。生父的雇佣关系被曝光
- 文穗的死因被重新定性为"他杀"
- 生父可能被追责（但设定中标为"不重要"，可只留一句新闻/对话）
- 玩家在文穗的空房间整理她的遗物

**结局文本方向**：
- 正义得到伸张，但文穗不会回来
- 玩家在整理遗物时发现文穗的碎信——她一直在保护玩家
- "等价交换"的最终理解：文穗用自己的沉默交换了玩家的安心
- 灯织发来消息："你还好吗。"——她还在等

### B-2：接受·妥协

**触发**：玩家选择"接受生父的补偿，不再追究"

**剧情走向**：
- 生父通过某种渠道联系玩家，提出补偿条件（钱/安排/不再骚扰）
- 玩家在绝望和疲惫中选择接受——不是因为原谅，而是因为太累了
- 侦探A/B的真相被永远埋葬
- 玩家用补偿的钱搬离了老城区

**结局文本方向**：
- 灰色妥协。真相被用钱买走，但良心不会
- 玩家搬走时经过文穗的水塔，最后一次站在那里
- 文穗的"等价交换"在这里变成了讽刺——有些交换是不对等的
- 灯织站在新公寓的阳台上看着玩家离开，没有说再见

## 四、路线 C：解离重演 — 玩家线

### 锁定后演出

玩家的解离障碍被揭示。记忆碎片拼合成完整真相：前夜跟踪→质问→失控→掐死→解离。轮回被重新定义为创伤记忆的强迫性重演。

### C-1：接受·清醒

**触发**：玩家选择"接受真相"

**剧情走向**：
- 玩家在幻觉/记忆的尽头面对自己
- 承认自己杀了文穗——不是"虐绞狂人格"，不是"另一个自己"，就是自己
- 轮回停止。不是因为它被"打破"，而是因为玩家不再需要它了
- 玩家在社区医院/心理咨询中开始面对现实

**结局文本方向**：
- 灰暗但清醒。接受罪行不是救赎，但至少是真实的
- 文穗的幻觉最后一次出现——不是恐惧，不是原谅，只是沉默地看了玩家一眼，然后消失
- 玩家说："早安，文穗。"房间里没有人回答
- 但这次不是解离，是告别

### C-2：否认·囚禁

**触发**：玩家选择"拒绝接受，继续寻找凶手"

**剧情走向**：
- 玩家拒绝承认自己是凶手
- 再次进入轮回——但这次轮回不会给出新的线索
- 玩家在无限循环中继续寻找"不存在的凶手"
- 文穗的幻觉越来越淡，最终连幻觉都不再出现

**结局文本方向**：
- 永恒的自我囚禁。比任何结局都残酷——玩家选择了幻觉
- 闹钟停在九点。空气里有草莓味。文穗在门口探头。
- "你今天又做噩梦了？"
- 你笑着说，没有。
- 然后你重新开始寻找凶手。

## 五、路线 NONE：漫长的告别 — 无凶手线

### 核心叙事

反推理。没有凶手——文穗的死是雨天意外，或者说，她早已决定离开（自主出走/告别），坠亡只是这场告别被暴雨扭曲后的样子。玩家追查出的每一个"嫌疑人"都是自己执念的投影：老头只是孤僻，侦探只是受雇劝返，自己只是没能说再见。**凶手是玩家的不肯接受。**

### 锁定条件（全部满足）

- 所有角色怀疑度 < 50（从未锁凶）
- 行程还原进度 = 100（完整理解文穗当天的动机）
- 发现完整告别信（碎信的全部三片：文穗房间 / 水塔 / 玩家公寓门缝）

### 锁定后演出

玩家在水塔下拼合三片碎信。告别信完整呈现：文穗早就写好了告别——她要离开这座城市，去找自己的出身答案，"不是逃离你，是去成为能回来见你的人"。那天她只是想最后看一眼这座城市。雨太大了。

### N-1：读信·放手

**触发**：玩家选择"读完信，接受告别"

**结局文本方向**：
- 没有凶手可以恨，是这个故事最残忍也最温柔的版本
- 玩家把信折好放进口袋，走下水塔。雨停了
- "再见"这个词，第一次被完整地说出来
- 标题回收：最漫长的告别，是没有来得及说的那一场

### N-2：拒信·回环

**触发**：玩家选择"不可能。一定有凶手"

**结局文本方向**：
- 软结局：玩家撕掉信，回到轮回
- 但从此每轮清晨，口袋里都会多出一片湿透的碎纸
- 读不读，是下一轮的事

## 六、路线 FAKE：金蝉 — 假死线

### 核心叙事

文穗没有死。她发现生父派人来"带回"她之后，策划了假死脱身：利用暴雨、观景台、一具无人认领的躯体（或仅是衣物与血迹的布置），制造自己坠亡的假象，金蝉脱壳逃离这座城市。玩家的调查越深入，越接近毁掉她用命换来的自由。

### 锁定条件（发现假死证据 ≥ 3）

| 证据 | 发现位置 | 内容 |
|------|---------|------|
| 尸源不符 | 社区医院/法医信息 | 遗体身高/旧伤与文穗记录对不上 |
| 死后目击 | 火车站/长途汽车站 | 有人在"死亡时间"之后见过穿雨衣的相似身影 |
| 车票存根 | 文穗房间夹层 | 一张未使用的假名长途车票，发车日期是死亡次日 |
| 提前清空的存折 | 便利店代收点 | 文穗死前一周分批取空了打工积蓄 |
| 给灯织的托付 | 灯织好感度≥80 | "如果他问起我，就说我死了。" |

### 锁定后演出

玩家追到长途汽车站/邻市，在人群里看见那个背影。她也看见了玩家。雨衣帽檐下，是活着的文穗。

### F-1：放她走

**触发**：玩家选择"转身离开，装作没看见"

**结局文本方向**：
- 玩家终于做到了文穗一直希望的事：让她自由
- 没有拥抱，没有告别，只有一个隔着人群的对视和一个几乎看不见的点头
- 回城的车上，玩家收到一条陌生号码的短信："等价交换。我用死亡换自由，你用沉默换我活着。"
- 这是所有结局里唯一一个文穗活着的世界——代价是永远失去她

### F-2：追到底

**触发**：玩家选择"追上去"

**结局文本方向**：
- 灰色结局。玩家抓住了她的手腕，也抓碎了她的计划
- 生父的人循着玩家的行踪找到了她
- 文穗看着玩家，没有怨恨，只有疲惫："你总是这样。"
- 她被带走了。这一次，是真的再也见不到了

## 七、解释层 CULT：阳极真神 — 邪神线（叠加于 A）

### 核心叙事

A 线的深层。阳极教不是妄想——**献祭真的有效**。老头靠仪式活过了本该死去的年岁，而"轮回"本身就是仪式的副产物：文穗的"阳寿"没有被完全吸收，溢出的部分缠绕在最执念她的人身上，形成了这个不断重演的雨天。玩家不是在调查，是在一场未完成的献祭内部打转。

### 叠加条件（在锁定 A 线的基础上，全部满足）

- cycleCount ≥ 4
- 收集邪神系线索 ≥ 3：
  - 祭坛符号与孤儿院"太阳房"壁画同源
  - 阳极地名单上有已死于"意外"的前例，死期全是雨天
  - 麻将馆老板娘："那老头，二十年没见老过。"
  - 轮回中只有玩家记得的细节，老头也记得（他在某轮说漏嘴）

**未满足叠加条件时**：A 线按 REAL 解释走 A-1/A-2。

### X-1：毁坛·渎神

**触发**：玩家选择"砸毁祭坛"

**结局文本方向**：
- 祭坛毁了，轮回的支点断了。雨声第一次停在半空
- 老头在瞬间老去二十岁，瘫坐在灰烬里
- 但文穗的"阳寿"也随祭坛散了——连轮回里的那个清晨都不会再有
- 玩家走出老头楼，天亮得刺眼。世界正常了，空了

### X-2：献祭·续命

**触发**：玩家选择"完成仪式"

**结局文本方向**：
- 最黑暗的结局。玩家读懂了仪式的另一种用法：把溢出的阳寿引向一个"容器"，可以让那个清晨永远凝固
- 玩家割开手掌按上祭坛。轮回不再是重演，是永驻
- 文穗每天早上都会探头说早安，永远十七岁，永远是那个雨天的前一刻
- 只有玩家知道窗外的雨永远不会停，也只有玩家在一天天老去

## 八、解释层 PSYCH：内室 — 精神疾病线（叠加于 C）

### 核心叙事

C 线的更深一层。不是"你杀了文穗"——是**文穗、老头、侦探、灯织，都是内室里的家具**。玩家长期住院/居家治疗，文穗是很多年前就不在了的人（妹妹/幼驯染，死于真实的意外），整场"调查"是药物减量后的一次大发作：老头=对衰老与死亡的恐惧，侦探=被监视的病识感，灯织=孤独本身，"凶手"=无法归因的丧失。轮回是治疗过程的隐喻——每一轮，都是一次咨询。

### 叠加条件（在锁定 C 线的基础上，全部满足）

- sanity < 20
- 发现"世界不一致"线索 ≥ 3：
  - 便利店小票的日期是同一天，但年份各不相同
  - 社区医院值班医生每轮都穿同一件毛衣，胸牌写着"主治医师"
  - 玩家公寓的窗，从任何角度都看不到街道
  - 药瓶标签撕掉的另一半在枕头下："每日两次，不可自行停药"

**未满足叠加条件时**：C 线按 REAL 解释走 C-1/C-2。

### P-1：醒来

**触发**：玩家选择"停止调查，去医院"

**结局文本方向**：
- 白墙。消毒水味盖过了草莓味。医生的毛衣是灰色的
- "你回来了。"医生说，"这次走了多远？"
- 玩家说出文穗的名字。医生没有纠正，只是递过水杯
- 窗外在下雨。只是普通的、会停的雨

### P-2：沉入

**触发**：玩家选择"这里就是真的"

**结局文本方向**：
- 玩家选择永远住在内室里
- 从此调查再无进展，但也再无痛苦。老城区永远是那个雨天
- 最后一幕切到外部视角：病床、点滴、护士交接班的脚步声
- 床上的人嘴唇动了动。像是在说"早安"

## 九、元层 STAY：早安·永远 — 无限轮回（软结局）

### 核心叙事

轮回不是诅咒，是礼物。每一轮的清晨文穗都活着——探头、草莓味、"早安"。知晓一切真相之后，玩家仍然可以选择：不出门，不调查，就陪她过完这一天。然后明天再来一次。**"凶手"是玩家的不肯告别本身**——而灯织是唯一的观众，她早就知道轮回，一直在等玩家变成和她一样的人。

### 解锁条件（清晨出现新选项「不出门，陪文穗过完今天」）

- 曾锁定过至少一条路线（lockedRoute 历史非空）
- endingsSeen ≥ 3

### 触发

- 连续 3 轮选择「陪文穗过完今天」→ 播放 `STAY.txt`

### 结局文本方向

- 第一天：奢侈。第二天：熟练。第三天：你开始记不清今天是第几个"今天"
- 灯织在楼下撑着伞看你的窗户，没有上来。她笑了——你终于懂她了
- 傍晚文穗还是会出门，还是会死。你学会了在她出门前睡着
- 软结局：播完回到轮回清晨，选项仍在。**留下或离开，永远可以重选**

---

## 十、元层 TRUE：九点零一分 — 告别（真结局）

### 解锁条件（全部满足）

- A、B、C 三条锁凶路线全部锁定过（跨周目累计）
- 曾进入过 STAY 结局
- 清晨出现最终选项「说再见」

### 剧情走向

- 最后一个清晨。玩家没有查线索，没有留下，而是对文穗说出完整的告别
- 把每一轮学到的话说完：她的身世、她的打工、她的害怕、她没写完的信——"我都知道了。我也该让你走了"
- 文穗安静地听完，笑了。她走出门，回头挥手
- 雨停。闹钟从 9:00 走到了 9:01——**第一次，时间前进了**

### 结局文本方向

- 不解释她去了哪里。所有真相在这一刻都不重要了
- 告别不是遗忘，是终于可以带着她往前走
- 最后一行：「再见，文穗。」——这一次，有人回答了
- 播放完整制作名单。游戏真正结束

## 十一、兜底结局：困局

**触发**：第7轮及以后，无任何角色怀疑度达50，且未满足 NONE/FAKE 锁定条件

**剧情走向**：
- 玩家困在无限轮回中，无法锁凶
- 文穗不断死去，玩家不断重来
- 最后一次轮回中，玩家发现自己已经不记得文穗的样子了

**结局文本方向**：
- 比所有结局都安静的绝望
- 你忘了她的脸。你忘了她的声音。你只剩下一个名字和一个雨天
- "她叫什么来着？"
- 雨没有回答

**与 STAY 的对照**：LOOP 是被动困住（查不出而遗忘），STAY 是主动留下（全知而不舍）。一个失去她，一个失去自己。

## 十三、新增变量（供 multi-truth-design.md / 实现参考）

```typescript
interface EndingSystemState {
  lockedRoute: 'A' | 'B' | 'C' | 'NONE' | 'FAKE' | null;
  overlay: 'CULT' | 'PSYCH' | null;      // 解释层，仅 A→CULT / C→PSYCH
  routesLockedEver: string[];            // 跨周目累计锁定过的路线（TRUE 条件）
  cultClues: string[];                   // 邪神系线索 ID
  worldGlitchClues: string[];            // 世界不一致线索 ID（PSYCH）
  fakeEvidence: string[];                // 假死证据 ID
  letterFragments: string[];             // 告别信碎片（3片，NONE 条件）
  stayStreak: number;                    // 连续选择"陪文穗"的轮数
  stayedEver: boolean;                   // 是否进入过 STAY（TRUE 条件）
}
```

### 判定优先级（每轮结算时）

1. TRUE（条件满足且玩家选「说再见」）
2. STAY（stayStreak ≥ 3）
3. 解释层叠加：CULT / PSYCH（已锁 A/C 且叠加条件满足 → 替换锁定演出）
4. 锁凶层：A / B / C / FAKE / NONE
5. 兜底：LOOP（第7轮起）
