## 0. 已定稿、不得回退的制作规范

本节汇总已确认的设计意见，优先级高于后文的示例数值与早期草案。后续所有角色、情绪差分和动画帧都必须遵守；若旧资产与本节冲突，应重制旧资产，而不是为旧资产保留例外。

### 0.1 统一立绘摄影棚模板

- 所有角色、所有情绪、所有动作帧统一使用 `430×606` 透明逻辑画布。
- 统一的是制作源文件，不只是游戏内“看起来差不多大”：画布宽高、镜头距离、人物基础缩放、头身比例、身体展示范围都必须一致。
- 默认构图为大半身像：从发顶完整显示至大腿中段。不能把某个角色做成全身像后再在运行时放大，也不能只展示到腰部来掩盖比例差异。
- 发顶安全边距目标为 `24–28px`；动作造成的发梢轻微起伏可以越出目标区间，但基础待机和六种情绪定格必须回到该区间。
- 发顶、下巴、肩线、腰线和大腿截断线使用同一组参考带。角色的真实身高、年龄和体型通过肩宽、躯干长度、骨架与姿态体现，不通过改变镜头远近体现。
- 同场角色的可见头部高度与面部尺度原则上相差不超过约 `5%`。切换人物时，玩家应先感到角色体型不同，而不是摄影机突然推近或拉远。
- 双手和角色标志性道具尽量完整入画。动作需要横向空间时可以改变手臂轮廓，但不得改变人物整体缩放，也不得用缩小角色换取空间。
- 同一角色所有帧保持相同头部中心、基础肩线和缩放；除非动作明确包含蹲下、后仰或前倾，否则脸部不应在切帧时无意义漂移。
- 预览器和正式播放器都按 `430×606` 原始纵横比显示，不再维护角色专属画布尺寸或角色专属 CSS 补偿。

统一模板参考带（用于画辅助线，不用于把不同骨架强行拉成同一人体）：

| 参考项 | `430×606` 画布中的目标区间 | 验收含义 |
|---|---:|---|
| 发顶 | `y = 24–28` | 基础待机和六情绪定格必须稳定；发丝动作可短暂越界 |
| 下巴 | `y = 158–182` | 控制脸与头部显示尺度；角色切换时不得明显跳档 |
| 肩线中心 | `y = 190–230` | 允许高领、耸肩和年龄差异，但镜头距离不变 |
| 自然腰线 | `y = 330–390` | 由真实躯干比例决定，不为填满画布而拉长身体 |
| 大腿截断带 | `y = 596–606` | 默认大半身结束位置；底边允许身体继续被画布自然裁断 |
| 头部水平中心 | `x = 190–240` | 以约 `x = 215` 为共同基准；动作偏移后应能回位 |

制作时先套模板检查发顶、下巴与头部中心，再检查肩线、腰线和截断带。前三项决定镜头是否统一，后三项用于发现躯干被不自然拉伸、压缩或裁短的问题。

### 0.2 共同美术语言

- 所有立绘必须保持明显、真实的像素绘制质感：轮廓、睫毛、瞳孔高光、发丝和衣褶都由清晰像素块组织，禁止高清插画套像素滤镜。
- 面部精细度、轮廓线粗细、阴影层级和服装材质表现以新版文穗、灯织为共同基准。
- 服装设计追求简约、高级和角色相关，不靠堆叠饰品制造“精细”。每一处扣件、补丁、耳环或配饰都必须承担身份、习惯或心理表达。
- 即使是剧情功能较轻的 NPC，也必须拥有可记忆的轮廓、标志媒介、基础动作习惯，以及至少一个能体现性格的情绪反应；参考《逆转裁判》的高辨识度角色演出，但保持本作克制、写实、阴郁的基调。

### 0.3 表情、视线与动作差分

- 只制作现有协议规定的六种标准情绪：`calm / happy / sad / angry / horror / insane`，不额外扩充情绪 ID。
- 六种情绪不是六张只替换眉眼嘴的头像。情绪可以并且应当改变手势、肩部、重心、道具使用和动作节奏。
- 没有明确剧情理由时，角色目光默认注视镜头／屏幕，与玩家建立交流。侧身、低头和转头可以存在，但瞳孔应尽量回看玩家。
- 移开视线必须表达明确含义，例如撒谎、羞怯、观察威胁或主动拒绝交流；不能只为让姿势显得活泼而随机看向画外。
- 允许类似《逆转裁判》的清楚停顿、关键姿势和动作反差，但禁止夸张变形、表情贴纸和与本作气质不符的漫画符号。

### 0.4 文穗不可回退的人物特征

- 文穗是“外表柔弱、内在坚强”，不是单纯怯弱。温顺感来自略微上挑而放松的眉形、柔和直视和偏瘦小体格。
- 眉头不能过度皱起；悲伤与站稳状态都要保留温和，避免把柔弱画成持续委屈或恐惧。
- 睫毛与眼部细节必须保持像素块组织，禁止出现脱离整体分辨率的高清睫毛线。
- 她的力量通过停止整理、站直、直视玩家和不再后退体现，而不是突然变成攻击性人物。
- 围裙、补丁与抹布是人物心理媒介；小调皮、站稳等情绪变化应允许改变手部动作和身体重心。

### 0.5 沈灯织不可回退的人物特征

- 灯织需要拥有出色、美丽、让人放心的第一印象；危险感不能依靠杀气，而来自平和、准确、始终掌握更多信息，以及不平等却真实的呵护。
- 她的内在不是匮乏或空洞，而是高高在上：只真正认同少数人，其他人在她眼中是值得照顾但浅薄的小动物。
- 服装保持原版式的简约、高级、低调昂贵；剪裁必须能体现身体结构，但不得重新堆叠复杂装饰。装饰限于有意义的小型耳环、金属扣和克制的材质差异。
- 眼形保持细长而平和；深色环状瞳孔只保留少量小高光。高光不能过大，眼神不能有明显杀气。
- 眉形更平稳，微笑更平和；可以增加少量下眼睫毛，但必须维持像素精度。
- 耳环必须结构完整、左右关系清楚，禁止残留断裂像素或悬浮像素。
- 动作必须精确、有主导感但不僵硬；开放手势、整理袖口和衡量动作都应像她主动安排交流，而不是呆站或机械摆拍。

### 0.6 验收与版本纪律

- 新角色先在统一模板中完成基础待机，再制作六情绪和动画，不允许每名角色重新定义自己的构图标准。
- 每轮美术验收至少同时查看：透明原图对比、真实游戏场景、对话框遮挡、桌面端和移动横屏。
- 比例验收必须把两名以上角色并排切换；只看单张“好不好看”不能证明统一。
- 已验收的脸、服装、像素语言和人物气质是后续编辑的不变量。制作动画帧时只改变本次动作需要改变的部位，禁止无意重绘身份。
- 阶段资产通过预览器验收后才能覆盖正式游戏资源，并保留可回退的上一版本。

## 1. 目标

本项目的角色动态不追求连续、写实的动画，而采用接近《逆转裁判》的演出思路：用少量高辨识度关键姿势、短促逐帧动作、有意停顿和音效，把人物性格写进动作本身。

角色即使只是阶段性 NPC，也必须拥有能被玩家记住的亮点。动态立绘不能只是“六张脸部表情 + 整张图片晃动”，而应让玩家在隐藏姓名时，仅通过剪影、手势和动作节奏也能辨认角色。

首批先完成文穗和沈灯织，以两人建立美术、资源和程序标准；确认在实际对话框中的表现后，再重构其他角色。

## 2. 核心原则

### 2.1 每个角色必须有自己的动作语法

每个角色都要定义以下五层信息：

1. **剪影锚点**：缩小后仍能辨认的发型、服装轮廓和站姿。
2. **静态习惯**：基础立绘中已经存在的习惯性姿势。
3. **标志媒介**：能承载人物心理的道具或身体部位。
4. **情绪动作链**：情绪改变时，手、肩、重心和视线一同变化。
5. **伪装破裂点**：关键剧情中，角色一贯的动作规律被打破。

文穗的核心媒介是抹布、围裙补丁和“把东西整理好”；灯织的核心媒介是手腕、袖口、耳环和“把自己恢复到完美位置”。

### 2.2 情绪标签不等于统一表演

现有协议保留六种情绪 ID：

```text
calm / happy / sad / angry / horror / insane
```

它们只负责选择角色的情绪状态，不规定所有人必须以同一种方式表演。

- 文穗的 `angry` 是第一次允许自己表达不满，不应画成攻击性暴怒。
- 灯织的 `angry` 是礼貌仍在、控制力度上升，不应大喊或咬牙。
- 文穗的 `insane` 用于幻觉错位、记忆裂解或轮回污染，不表示文穗本人疯狂。
- 灯织的 `insane` 表示她彻底放弃平等伪装，进入安静而高位的凝视，不画成疯笑。

### 2.3 动画服务台词节拍

标准演出节奏：

```text
待机 → 开始说话 → 短循环嘴型 → 关键词前停顿
     → 标志动作或瞬间反应 → 停在新的情绪姿势 → 下一句台词
```

动画不是独立装饰。每个非循环动作都必须回答：“它在这句台词里揭示了什么？”

### 2.4 有辨识度地使用夸张

允许像《逆转裁判》一样让情绪姿势具有清晰节奏、鲜明轮廓和主角级辨识度；人物不必被画成平庸路人。但夸张应来自手势、肩线、重心、道具和停顿，仍须保持本作写实、阴郁的悬疑基调：

- 可以扩大姿势变化，让不同情绪改变人物的手、肩、躯干斜线和重心；不使用卡通式肢体拉伸或五官变形。
- 可以使用一至两帧强烈停顿，不使用漫画符号和表情贴纸。
- 可以用道具、眼神和重心制造反差，不依赖全屏抖动。
- 关键动作越少，重复出现时越有识别力。

### 2.5 默认视线规则

- 只要剧情没有明确要求角色观察物品、看向另一角色、躲避目光或追踪画外事件，角色视线应默认注视镜头／屏幕，即注视玩家。
- 头部可以侧倾或身体可以转向，但瞳孔仍应尽量回到玩家，保持视觉交流。
- 短暂移开视线必须具有叙事含义，例如撒谎、羞愧、观察威胁或刻意拒绝交流；不能仅为了让姿势更活泼而随机看向画外。
- 动画结束后的情绪定格应重新看向玩家，除非“回避目光”本身就是该状态的持续信息。

## 3. 美术与构图标准

### 3.1 画面规格

- 保留当前大半身构图：头部至大腿中段，双手尽量完整入画。
- 所有角色单帧逻辑画布统一为：`430 × 606`。
- 画布、镜头距离与大半身取景是一项共同制作标准，不是导入游戏后再用 CSS 调整出来的近似效果。
- 标准取景为发顶至大腿中段；头顶、下巴、肩线、腰线和大腿截断线必须落在同一组参考区间。姿势可以改变手臂和重心，但不能借动作改变人物的基础头身尺度。
- 标准可见头部高度（发顶至下巴）控制在约 `180–195px`，同场角色的面部尺寸差异原则上不超过约 `5%`；年龄与脸型差异可以保留，但不能因此让某个角色整体缩小一个层级。
- 发顶安全边距控制在约 `20–30px`。高挑角色通过裁去更多大腿下方来保持大半身构图，不能为了容纳更长身体而缩小头部。
- 肩宽、眼睛和手掌作为第二级比例校验项；角色切换时应先感到身高和体型不同，而不是镜头远近不同。
- 同一角色的所有帧必须保持完全相同的画布、脚点、基准线和缩放比例。
- 发顶、手指、袖口和道具不得越出安全区。
- 透明背景；最终显示使用 `image-rendering: pixelated`。

### 3.2 像素规范

- 必须呈现手工组织的硬边像素块，不接受高清插画直接套像素滤镜。
- 轮廓线粗细、眼睛像素密度、头身比例与当前新版文穗和灯织一致。
- 不使用平滑睫毛、空气笔刷、柔焦边缘或亚像素线条。
- 每个动作先画关键姿势，再补少量中间帧；不追求无意义的高帧率。
- 人物本体不使用连续缩放和旋转代替逐帧动作。

### 3.3 动画帧预算

| 动画类型 | 建议帧数 | 播放方式 |
|---|---:|---|
| 基础待机 | 3–4 | 低频循环，1.8–3.5 秒一轮 |
| 说话循环 | 2–3 | 文字打印期间循环 |
| 情绪切换 | 3–5 | 播放一次，停在情绪定格帧 |
| 标志动作 | 5–8 | 播放一次，可在关键帧停顿 |
| 伪装破裂／剧情动作 | 8–12 | 播放一次，禁止自动跳过关键停顿 |

不要求六种情绪各自拥有完整循环。六张情绪定格是基础，动画集中投入在待机、说话、两至三个标志动作和一个关键剧情动作上。

## 4. 文穗动态设计

### 4.1 人物核心

文穗 14 岁。她外表柔弱、温顺，内在有被长期压住的韧性。上挑而放松的眉形、温和的眼神和偏瘦小的体格体现柔弱感；端正站姿、动作完成度和关键时刻不后退体现坚强。

她“懂事”并非天生没有欲望，而是从孤儿院经历中学会：必须通过家务、成绩和乖巧证明自己值得被爱。最近因为真正信任玩家，她开始露出小调皮、任性和隐瞒。这些变化应当被动态立绘清楚区分。

### 4.2 剪影与基础姿势

- 棕色短发微卷至下巴，发尾略乱，有自己修剪的痕迹。
- 圆脸、琥珀色眼睛、身形偏瘦小。
- 做家务时穿带小补丁的绿色围裙；服装简朴、干净。
- 基础姿势仍保留抹布，但不始终双手紧抓。
- 背部比第一印象更直，这是她在孤儿院养成的习惯。
- 基础重心略向内收，空间占用小；进入坚定状态后重心才真正站稳。

### 4.3 标志动作语言

#### A. `fold-cloth`／把抹布叠好

文穗的核心待机动作。她会把已经足够整齐的抹布再次折叠，表现“不能闲着、必须有用”的心理。

- 平静时：两次折叠后停下。
- 撒谎或紧张时：多折一次，发现无处可折后捏住边角。
- 难过时：动作变慢，但仍坚持把它整理好。
- 生气时：第一次不整理，直接把抹布攥在手里。

#### B. `touch-patch`／摸围裙补丁

她在担心自己成为负担，或提及金钱、礼物、回报时，下意识摸一下围裙补丁。动作幅度很小，适合成为可重复观察的心理线索。

#### C. `small-mischief`／藏起小得意

体现她最近出现的真实自我：身体轻微向一侧倾，抹布藏到背后，眼睛先避开玩家再偷偷看回来。不是偶像式可爱动作，而是一个长期乖巧的孩子第一次允许自己开玩笑。

#### D. `stand-ground`／站稳

文穗的力量动作。她停止折叠和抚摸补丁，双手自然放下或将抹布握在一只手里，背部挺直，直接看向玩家。动作不大，但应与平时内收姿态形成明显反差。

#### E. `memory-slip`／记忆错位

仅用于幻觉、轮回污染和玩家线真相逼近：某个日常动作重复到中途突然跳回第一帧，或抹布的位置出现一次不连续变化。避免血腥、鬼脸和故障贴图，把异常放在“动作重复得不对”上。

### 4.4 六种情绪定格与反应

| 情绪 | 定格姿势 | 动态反应 |
|---|---|---|
| `calm` | 温和抬眼，双手自然整理抹布 | 低频眨眼、轻微呼吸、完成一次折叠 |
| `happy` | 笑意真实，身体略向玩家靠近 | 把抹布藏到背后再探头看回来；发尾轻动 |
| `sad` | 眉头只轻微收拢，不做过度哭相 | 折叠速度变慢，拇指抚平不存在的褶皱 |
| `angry` | 眉形变平，眼神第一次不退让 | 停止整理，攥住抹布，随后做 `stand-ground` |
| `horror` | 呼吸停住、肩部收紧、瞳孔锁定威胁 | 手先下意识护住围裙前方，再后退半步 |
| `insane` | 表情过于安静，像记忆中被固定的一帧 | 日常动作发生一次错误重复，最终停在直视玩家的姿势 |

### 4.5 首批动画清单

| 动画 ID | 优先级 | 用途 |
|---|---:|---|
| `fumi.idle.calm` | P0 | 基础待机 |
| `fumi.talk.calm` | P0 | 普通说话循环 |
| `fumi.gesture.fold-cloth` | P0 | 核心习惯动作 |
| `fumi.gesture.small-mischief` | P0 | 真实自我露出 |
| `fumi.react.stand-ground` | P0 | 柔弱外表下的坚强 |
| `fumi.react.recoil` | P1 | 被逼问或受到威胁 |
| `fumi.special.memory-slip` | P1 | 轮回／玩家线异常演出 |

## 5. 沈灯织动态设计

### 5.1 人物核心

沈灯织 24–26 岁。她拥有出色、美丽而令人放心的第一印象；服装简约、高级、低调昂贵。她并非空洞或冷血，而是内心高高在上：真正认可的人极少，其他人对她而言是值得呵护但浅薄的小动物。

她对玩家存在真实的智识认同，对文穗的关心也并非虚假，但这种关心从一开始就不是平等关系。她的危险感不能依靠杀气，而要来自“温柔、准确、始终比别人多知道一点”。

### 5.2 剪影与基础姿势

- 黑色长发、偏分刘海；高挑、端正。
- 细长眼，深色环状瞳孔内保留少量高光；眼神平和，不带攻击性。
- 深色高领与利落剪裁，服装装饰克制，只保留高级材质、金属扣和小型耳环。
- 基础姿势为一只手自然搭住另一只手腕，身体线条简洁、稳定。
- 手势必须精确，手指不能随意张开；每次动作结束都能回到几乎相同的位置。
- 默认 `calm` 的两条手臂必须与裙身形成清楚的遮挡或接触关系，不能在手肘、腰侧、前臂内缘留下透明背景缝隙；静态主体应保持单一连通的抠图轮廓。
- 长发外缘用连续、平稳的像素阶梯组织，禁止出现零碎悬浮像素、毛边噪点或以平滑抗锯齿伪造“顺滑”。
- 黑白灰不等于把头发和礼服涂成黑块：长发必须保留阴影、发束中灰与高光分组；礼服必须以不同灰阶读出领口、肩部、胸部裁片、袖口、腰线和裙褶，且与头发材质明确区分。

### 5.3 标志动作语言

#### A. `reset-cuff`／复位袖口

灯织的核心待机动作。她轻轻整理袖口，再让手回到另一只手腕上。这个动作表示她始终在维持自己和现场的秩序。

- 平静时：动作自然，几乎难以察觉。
- 生气时：拇指在袖口停留更久，力度增加。
- 恐惧时：第一次没有一次整理好，随后立刻补做第二次。
- 伪装破裂时：她不再整理袖口。

#### B. `touch-earring`／触碰耳环

她需要重新判断对方、听到意外信息或短暂产生真正兴趣时，指尖会靠近耳环。动作不是卖弄美貌，而是给思考争取半秒停顿。

#### C. `measure`／衡量

她略微侧头，眼睛保持半眯，食指在另一只手腕上轻点一次。这个动作应让玩家感到自己正在被温柔地评估。

#### D. `almost-reach`／几乎伸手

灯织真正孤独或对玩家产生接近冲动时，手离开手腕、向前伸出少许，随后在触及任何东西前收回并复位。这是她最接近脆弱的动作。

#### E. `stop-resetting`／停止复位

她的伪装破裂动作。双手自然放下，肩颈变得更直，笑容淡去，眼睛完全看向玩家。与其增加夸张动作，不如让她第一次“不再修正自己”。

### 5.4 六种情绪定格与反应

| 情绪 | 定格姿势 | 动态反应 |
|---|---|---|
| `calm` | 平和微笑，一手搭住另一只手腕 | 低频眨眼、耳环一像素微动、完成一次袖口复位 |
| `happy` | 笑意稍深，但姿态仍然克制 | 眼睛短暂柔和，手指轻触耳环后回位 |
| `sad` | 嘴角放平，视线稍微落向玩家身侧 | 手做 `almost-reach`，停顿后收回 |
| `angry` | 表情仍礼貌，下眼睑与手指力度发生变化 | 拇指压住袖口，食指停止轻点，身体向前极小幅度压近 |
| `horror` | 眼睛短暂睁开，呼吸和复位节奏被打断 | 袖口第一次没有整理好；一帧失态后迅速恢复 |
| `insane` | 微笑比平时更安静、更满足，瞳孔稳定锁定玩家 | 双手松开、不再复位，进入 `stop-resetting` 的高位凝视 |

### 5.5 首批动画清单

| 动画 ID | 优先级 | 用途 |
|---|---:|---|
| `touko.idle.calm` | P0 | 基础待机 |
| `touko.talk.calm` | P0 | 普通说话循环 |
| `touko.gesture.reset-cuff` | P0 | 核心习惯动作 |
| `touko.gesture.measure` | P0 | 温柔而不平等的观察 |
| `touko.react.almost-reach` | P0 | 稀有的真实孤独 |
| `touko.react.composure-break` | P1 | 短暂失态后恢复 |
| `touko.special.stop-resetting` | P1 | 伪装破裂／关键结局状态 |

## 7. 剧本与 Agent 协议

当前对话格式继续兼容：

```text
对话|人物|情绪|文本
```

新增独立动作指令，避免与可选物品字段发生歧义：

```text
动作|文穗|small-mischief
对话|文穗|happy|才、才没有偷偷瞒着你什么。

动作|沈灯织|measure
对话|沈灯织|calm|你的小松鼠最近好像很忙。
```

执行边界：

- 事实守门不处理动作，只控制允许透露的事实。
- 导演根据剧情节拍提出 `actionIntent`。
- 审查确认动作不会提前泄露真相或破坏人物知情边界。
- 编剧只能从当前角色的动作白名单中选择动作 ID。
- 解析器拒绝未知动作；拒绝时回退到对应情绪静态立绘。
- 关键动作设置冷却和场景条件，避免模型在普通对话中反复使用。

建议导演计划增加：

```json
{
  "performance": [
    {
      "character": "fumi",
      "action": "small-mischief",
      "triggerBeat": "文穗用拙劣借口掩饰自己的行程",
      "importance": "character"
    }
  ]
}
```

## 8. 播放状态机

角色播放器建议采用以下优先级：

```text
关键剧情动作 > 瞬间反应 > 标志动作 > 说话循环 > 情绪待机 > 平静待机
```

基本流程：

```text
角色入场
  → 对应情绪待机
  → 文本开始时进入说话循环
  → 收到动作指令时，在安全帧结束说话循环
  → 播放一次动作
  → 根据动作配置停在末帧或回到情绪待机
```

程序要求：

- 新文本可以中断普通动作，但不可跳过关键剧情动作的核心帧。
- 快进模式压缩停顿，不删除信息性关键姿势。
- 自动模式等待非循环动作完成后再翻到下一句。
- 浏览器开启 `prefers-reduced-motion` 时，直接显示动作末帧并保留音效提示。
- 资源加载失败时回退到现有静态情绪 PNG。
- 不允许动画改变角色逻辑位置，避免遮挡对话框和移动端 UI。

## 9. 音效与演出配合

动画音效必须轻量，不能每个眨眼和嘴型都播放声音。

文穗可用：

- 布料轻擦声：折叠抹布、摸围裙补丁。
- 极轻的衣料绷紧声：攥住抹布、站稳。
- 记忆错位时使用一次短促的磁带跳齿或时间断裂声。

灯织可用：

- 袖口与金属扣的轻响。
- 耳环细小碰撞声，只在特写式关键动作中使用。
- 停止复位时不加夸张音效，使用环境声骤降或短暂静音制造强调。

### 阶段 B：最小动态原型

1. 文穗 `idle.calm`、`talk.calm`、`fold-cloth`。
2. 灯织 `idle.calm`、`talk.calm`、`reset-cuff`。
3. 实装精灵表播放器，但保持静态 PNG 回退。
4. 验证打字、快进、自动播放、切换说话者和切换情绪。

阶段 B 技术底座（2026-07-21）：

- 已新增统一动画 Manifest 类型及校验器，任何非 `430×606` 的角色动画清单都会被判定为无效。
- 已新增可变逐帧时长计算；停顿、眨眼和关键词强调不再被迫共用统一 FPS。

- 播放器暂不接入正式 `CharacterSprite`；必须先完成并验收文穗、灯织的真实关键帧，禁止用 CSS 缩放、旋转或抖动冒充角色动画。
- 已建立 `public/assets/characters/animated/{character}/manifest.plan.json` 制作清单，逐帧记录动作含义、停留时间、循环方式和减少动态落点。`.plan` 表示美术尚未完成，播放器不得加载。

### 阶段 C：角色亮点动作

1. 文穗 `small-mischief`、`stand-ground`、`memory-slip`。
2. 灯织 `measure`、`almost-reach`、`stop-resetting`。

### 阶段 D：扩展其他 NPC

系统稳定后，依次重构周德明、侦探 A、侦探 B，再补陈慧慧和刘仁光。每名 NPC 至少拥有：基础待机、说话循环、一个标志动作、一个伪装破裂动作。

## 11. 验收标准

- 隐藏角色姓名，仅看基础轮廓和动作即可区分文穗与灯织。
- 文穗的柔弱和坚强同时存在，不因悲伤表情变成单纯软弱。
- 灯织第一印象令人放心，不依赖杀气表达危险；高位感来自精确和不平等的温柔。
- 六种情绪都改变角色的姿势或行为节奏，而非只替换眉眼嘴。
- 标志动作在普通剧情中可重复识别，在真相场景中能产生新的含义。
- 动画与文字打印、快进、自动模式和场景切换没有竞争状态。
- 动画资源失败时，现有静态立绘仍可完整游玩。
- 桌面端、窄屏和移动横屏均不遮挡对话主体与操作区域。
- 动态效果不会破坏明显的像素质感。

## 12. 暂不处理的范围

- 暂不使用 Spine、Live2D 或完整骨骼动画。
- 暂不为每种情绪制作长循环动画。
- 暂不允许编剧 Agent 自由描述并生成不存在的动作。
- 暂不覆盖当前正式角色资源；关键姿势和原型通过评审后再替换。
- 暂不同时重绘所有 NPC，避免在主角动态标准尚未稳定前扩大返工范围。
