# 剧情写作规范：减少模板化表达

适用于《漫长的告别》运行时编剧的正文生成与修复。叙述贴近玩家当下可感知的事物，人物语言服从角色设定。事实和状态权限以 [剧情契约](agent-story-contract.md) 为准，行动过程及中断服从程序结算。

本文参考 [lieflat-less-ai-tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone/blob/main/SKILL.md)，按游戏小说体裁改编。原项目用于成稿后的局部清理；这里把适用内容作为编剧落笔指导及同一次输出前的自检，不建立 Skill 加载器，也不增加模型调用。来源统计不作为本游戏的质量阈值或检测准确率。

## 规则如何适配剧情

| 原规则 | 本项目的用法与边界 |
| --- | --- |
| 1. 翻案腔 | 旁白不要先替玩家假设一个误解，再给普通观察套反转。直接表达有依据的观察；真实误认后的纠正、角色否认、反讽和必要的对照可以保留。不能删除否定事实来迁就句式。 |
| 2. 顿号罗列 | 连续罗列使句子拥挤时调整句内结构，必要对象逐项保留。物证清单、问答中的指代项和按顺序执行的步骤不得概括丢失。 |
| 3. 相邻句同构 | 避免每句都采用同样的动作加补充说明，必要时调整其中一句。不同角色的问答、口癖和有意文学排比不机械打散；不凭句长相近判错。 |
| 4–5. 破折号和冒号 | 不用标点给普通判断制造揭晓或报告式总结。保留人物引语、话语中断、合理停顿和正常说明；机器协议中的分隔符不参与文风处理。 |
| 6. 标题序数 | 不移植为运行时限制：可播放正文已有行协议，不使用文章小标题。文档标题、菜单编号和有指代作用的步骤保持各自用途。 |
| 7. 理想化拟人比喻 | 不用理想化职业人格包装已表明的行为。普通比喻、拟人或角色的文学表达按语境保留，不统一改成白描。 |
| 8. 具体信息与动词 | 已获准的动作、对象和时间应清楚表达，避免被空泛概括盖掉。把绕行的动词表达理顺，但绝不为增加具体性编造信息。语言精简不能抹去实际调查过程。 |
| 9. 总结式起手 | 旁白少用报告式起手，直接进入观察或叙事。自然对话不统一清洗成同一种语气。 |
| 10. 五类翻译腔 | 仅处理难读的堆叠定语、冗余时间框架、重复话题套语、机械连接词及同义解释句；必要的时点、讨论范围、逻辑关系与新判断保留。不得扩展为所有长句或被动句都要改。 |
| 11. 评论指向缺失 | 非开场旁白突然评论而对象不明时，点明已出现的对象。角色间自然省略与接话不受此限制，不借补主语添加心理解释。 |

## 初稿和语言自检的区别

初稿仍须按获准计划呈现行动、关键问答、途中遭遇和中断；允许在既有授权范围内正常写作。不能把原 Skill 的信息守恒误解成只能照抄导演提纲，也不能因追求简短而省略调查过程。

成稿后的语言自检只调整明确命中的措辞，不能顺便重写整个回合。保持原有事实、语气强弱和否定，保留人物发言归属、问答依赖、演出顺序、选项意图、认知事件位置和协议指令。不确定某句是否有问题时保留原句。已接受剧情与存档不追溯改写。

这项自检不妨碍现有事实和协议修复。正文确实违反授权或协议时，编剧仍须依据具体问题修复并返回完整场景；修复后的内容继续经过现有审查再提交状态。

## 局部措辞示例

以下只展示语言变换，示例不授权在游戏中新增物件或事件。

- 原句：你完成了对门锁的检查。改写：你检查了门锁。动作不变。
- 原句：门依然锁着。这说明门还没有打开。改写：门依然锁着，仍未打开。只调整同义解释，不增加锁的成因。
- 保留：“我没见过她，也不知道她去了哪里。”角色的否定与不知情必须保留。
- 保留：“等一下——”打断有演出作用，不能因为出现破折号而删除。
- 保留：约定十点到场。不能为去掉具体报时改成“过一会儿”，也不能把尚未发生的约定写成已兑现。

## 实现与验证边界

精简运行版位于 `src/agents/mystery/prompts.ts` 的 `WRITER_SYSTEM_PROMPT`。现有编排和正文修复通过 `buildWriterSystemPrompt` 共用它；没有修改文风审查的拒绝条件，没有新增关键词拦截或自动删句处理。本规范不宣称覆盖 legacy 的独立提示词路径。

本地测试只能检查集成与既有契约没有破坏，不能证明模型的语言质量已经改善。效果评估应固定模型与场景，对照自然度、角色差异、行动演出是否完整，以及额外重试情况。不能仅以禁词或标点减少作为通过依据。
