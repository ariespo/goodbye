# 《漫长的告别》多真相/多结局系统设计

> **重构版 v2** — 本文档已对齐 `重构后设定.txt` 与新三层结局体系（见 `ending-design.md`）。

---

## 核心设计理念

**"真相不是被发现的，是被锁定的。"**

真相体系分三层：

```
锁凶层（谁是凶手）      A 老头 / B 侦探 / C 玩家 / NONE 无凶手 / FAKE 假死
解释层（这一切是什么）   REAL 现实 / CULT 邪神（叠加于A） / PSYCH 精神疾病（叠加于C）
元层（要不要离开）      STAY 无限轮回（软结局） → TRUE 告别（真结局）
```

玩家通过多轮轮回逐步累积对各角色的怀疑度。谁先到达 50，谁就是真凶（A/B/C）。NONE/FAKE 由证据链而非怀疑度锁定。解释层在已锁路线之上按深层线索叠加，未满足时按现实（REAL）解释。元层跨越所有路线，是对轮回本身的态度。

这与旧版"四种真相滤镜"不同——锁凶层不是"同一线索不同解读"，而是"不同调查路径发现不同证据，指向不同凶手"；解释层才承担"重释一切"的职能，且只在高轮回、深线索时开放。

## 一、三条真相详解

### 路线 A：「阳极献祭」—— 凶手是独居老头周德明

**触发条件**：
- 独居老头周德明怀疑度 ≥ 50

**核心叙事**：
文穗在调查自己孤儿院身世的过程中，前往老头楼附近打听信息。老头是"阳极教"成员，相信"在至阳之地生活过的人"体内积"阳寿"，献祭可续命。文穗幼时孤儿院被院长刻意做成"最温暖光明之地"，反成"阳极地"标准。老头以"避雨"为由诱文穗上楼，实施献祭仪式后推下楼，伪装坠亡。

**证据链**：

| 线索 | 发现位置 | 内容 |
|------|---------|------|
| 阳极地名单 | 老头楼内室祭坛旁 | 记载符合条件的"至阳之地"人名，文穗在其中 |
| 隐秘祭坛 | 老头楼内室 | 仪式用具、符号、文穗的随身物（"容器"） |
| 麻将馆老板娘证词 | 老头楼下 | "那天听到楼上很响一声"、"以前常去黔灵山最近不去了" |
| 文穗的笔记本（水塔） | 废弃水塔 | "周爷爷好像知道孤儿院的事" |
| 坠楼现场痕迹 | 老头楼后方 | 文穗的鞋与地面撞击角度不符合意外滑落 |

**叙事逻辑**：
1. 文穗从笔记本中得知老头住的老楼与孤儿院旧址在同一片区
2. 她去老头楼附近打听孤儿院信息
3. 老头认出她符合"阳极地"标准
4. 以避雨为由诱上楼
5. 仪式后推下楼，制造"雨天坠亡意外"

**关键设计**：老头是表面最无害的角色——笑眯眯分糖果、退休工人。玩家如果前三轮忽视了他，到第4轮复盘时才发现他的怀疑度被忽视，需要紧急回访。

### 路线 B：「失手与掩盖」—— 凶手是侦探A赵刚（B林静协助掩盖）

**触发条件**：
- 侦探A赵刚怀疑度 ≥ 50

**核心叙事**：
侦探A/B受雇于文穗生父，任务是评估并"必要时带回"文穗。暴雨打乱了计划——A在废弃水塔附近强行拦住文穗"约谈"，文穗激烈反抗并试图逃跑，A情急之下失手致其死亡（头部撞击水塔基座）。B到达后迅速冷静，指示A将尸体移至山腰废弃观景台，伪装为雨天坠亡。

**证据链**：

| 线索 | 发现位置 | 内容 |
|------|---------|------|
| 侦探A身上的抓痕 | 侦探小旅馆/步道遭遇时观察 | 文穗挣扎时留下 |
| 文穗指甲缝里的纤维 | 死亡地点/法医信息 | 与赵刚夹克面料匹配 |
| 通讯记录 | 侦探小旅馆 | A与B的通话记录，时间与文穗死亡时段吻合 |
| 水塔基座血迹 | 废弃水塔 | 暴雨冲淡但未完全冲掉 |
| 旅馆老板娘证词 | 侦探小旅馆 | "那天上午男客匆匆回来，手上好像有伤" |
| A慌乱 vs B冷静 | 对话/遭遇时观察 | A紧张捏烟蒂、手抖；B表情平稳、语速不变 |

**叙事逻辑**：
1. 生父雇佣A/B评估并"必要时带回"文穗
2. 暴雨封路打乱计划，A决定提前行动
3. A在废弃水塔附近拦住文穗
4. 文穗反抗逃跑中摔倒，头部撞击水塔基座
5. A失手致死后慌乱，B到达后冷静指挥掩盖
6. 两人将尸体移至观景台，伪装坠亡

**关键设计**：侦探A是玩家直觉最强的嫌疑人（盯楼、尾随、军人站姿、北方口音），但他是"红鲱鱼还是真凶"取决于玩家的调查方向。如果玩家早期过度关注他而忽视其他人，可能错过其他路线的关键证据。

### 路线 C：「解离重演」—— 凶手是玩家自己

**触发条件**（满足任意）：
- 玩家自疑度 ≥ 50
- 在社区医院发现药瓶真相 + 在家中发现碎信/指甲组织
- 多轮既视感累积到临界值

**核心叙事**：
真实凶杀发生在轮回锚定日的**前一夜**。玩家跟踪文穗，误读她与体育老师（实为性骚扰）、侦探（实为劝返）的互动。当晚质问文穗，文穗因保护玩家而隐瞒真相，玩家连环质问得不到回答，失控掐死文穗。次日晨解离发作，遗忘罪行，进入"轮回"——实为创伤记忆的强迫性重演。

**证据链**：

| 线索 | 发现位置 | 表面 | 深层 |
|------|---------|------|------|
| 药瓶 | 玩家公寓床头柜 | "感冒药" | 利培酮（抗精神病药物），标签被撕掉一半 |
| 请假电话记录 | 中学门卫 | "谁打的？" | 来自玩家自己的手机号 |
| 指甲缝组织 | 玩家自己 | "什么时候蹭的？" | 文穗挣扎时的皮肤组织 |
| 碎信 | 文穗房间/垃圾桶 | "写了一半的作业" | 文穗试图写给玩家但没完成的告别信 |
| 既视感/幻觉 | 跨轮回累积 | "似曾相识" | 前夜跟踪文穗的真实记忆被解离重组 |
| 值班医生证词 | 社区医院 | "你最近睡眠不好" | 玩家在服用抗精神病药，有"断片"史 |

**叙事逻辑**：
1. 前日白天：玩家跟踪文穗，目睹她被体育老师骚扰、与侦探交谈
2. 玩家误读为"文穗与体育老师亲密"、"文穗和陌生人关系不一般"
3. 当晚：玩家质问文穗，文穗为保护玩家而隐瞒
4. 连环质问无果 → 嫉妒、不安、失控 → 掐死文穗
5. 次日晨：解离发作，遗忘罪行
6. "轮回"=创伤记忆强迫重演——每次"还原行程"都是重演前日跟踪的记忆
7. 请假电话是玩家早上解离状态下打的

**关键设计**：自疑度的积累是缓慢的——请假电话的异常、既视感、药瓶标签、指甲缝组织，每一条单独看都可以有其他解释，但累积到一起指向不可接受的真相。

---

### 路线 NONE：「漫长的告别」—— 没有凶手

**触发条件**（全部满足）：
- 所有角色怀疑度 < 50
- 行程还原进度 = 100
- 集齐告别信三片碎片（文穗房间 / 废弃水塔 / 玩家公寓门缝）

**核心叙事**：
反推理。文穗的死是雨天意外——或者说，她早已决定离开这座城市去寻找身世答案，坠亡只是这场告别被暴雨扭曲后的样子。玩家追出的每个"嫌疑人"都是执念的投影。凶手是玩家的不肯接受。

**关键设计**：这是"什么都查对了、但谁都没怀疑错"的玩家才能抵达的路线。要求玩家完整理解文穗的动机（行程100），而不是急于归罪。

---

### 路线 FAKE：「金蝉」—— 文穗假死脱身

**触发条件**：
- 发现假死证据 ≥ 3（尸源不符 / 死后目击 / 假名车票 / 提前清空的存折 / 灯织的托付〔好感≥80〕）

**核心叙事**：
文穗没有死。她察觉生父派人来"带回"她之后，利用暴雨策划假死，金蝉脱壳逃离。玩家的调查越深入，越接近毁掉她用"死亡"换来的自由。锁定后玩家会在邻市车站看到活着的她，面临最终抉择：放她走（F-1）或追到底（F-2）。

**关键设计**：唯一一条文穗活着的路线。证据分散在 A/B/C 三条路线的调查动线上，只有横向比对的玩家才会起疑。

## 一·五、解释层（叠加真相）

### CULT「阳极真神」—— 邪神线（叠加于 A）

- **条件**：锁定 A + cycleCount ≥ 4 + 邪神系线索 ≥ 3（祭坛符号与孤儿院"太阳房"同源 / 名单上雨天死亡前例 / "老头二十年没老过" / 老头也记得轮回）
- **重释**：献祭真的有效。轮回是文穗溢出的"阳寿"缠绕玩家形成的副产物。结局 X-1 毁坛 / X-2 献祭。

### PSYCH「内室」—— 精神疾病线（叠加于 C）

- **条件**：锁定 C + sanity < 20 + 世界不一致线索 ≥ 3（小票年份错乱 / 医生的"主治医师"胸牌 / 看不到街道的窗 / 药瓶标签另一半）
- **重释**：文穗多年前就不在了。老头=对死亡的恐惧、侦探=被监视感、灯织=孤独本身，整场调查是一次大发作，每轮=一次咨询。结局 P-1 醒来 / P-2 沉入。

**未满足叠加条件时，A/C 按 REAL（现实）解释走原结局。**

## 一·六、元层：STAY 与 TRUE

- **STAY「早安·永远」（软结局）**：锁定过≥1条路线 + endingsSeen ≥ 3 后，清晨解锁选项「不出门，陪文穗过完今天」。连选 3 轮触发。播完可反悔，回到轮回。凶手是"不肯告别"本身；灯织是唯一观众。
- **TRUE「九点零一分」（真结局）**：A/B/C 全锁定过（跨周目）+ 曾进入 STAY → 清晨解锁「说再见」。完整告别后雨停，闹钟走到 9:01，时间第一次前进。游戏真正结束。
- **与 LOOP 困局的对照**：LOOP 是被动困住而遗忘她；STAY 是全知而主动留下。一个失去她，一个失去自己。

## 二、非锁凶但必须存在的真相层

### 便利店员陈慧慧 — 25 揭发烟雾弹

- 不善与人交往，笨拙的礼貌和固定笑容被误读为越界关注
- 令人不安但非杀机
- 永远无法锁定为凶手

### 体育老师刘仁光 — 25 揭发烟雾弹

- 有色胆无色心——性骚扰但未构成致死主因
- 可能间接把文穗推向危险路线（她为躲避他而改变行程）
- 永远无法锁定为凶手

### 学姐沈灯织 — 知情观察者 + 孤独共鸣

- 怀疑度永不可到 50
- 察觉文穗与侦探接触、文穗"想跑"
- 不主动伤害，也不阻止可能发生的事
- 期待玩家失去文穗后变成和她一样的"孤独者"
- 好感度越高，透露的信息层级越深（见下文）

## 三、核心变量系统

### 3.1 轮回计数器（cycleCount）

- 隐性变量，每次重置自动 +1
- 影响：解锁新的对话选项、新的可调查内容、NPC 态度变化
- 显示位置：状态面板角落

### 3.2 怀疑度（suspicion）— 按角色计

```
独居老头（周德明）  [0-50]  初始: 0
侦探A（赵刚）       [0-50]  初始: 0
侦探B（林静）       [0-50]  初始: 0
玩家自疑度          [0-50]  初始: 10
便利店员（陈慧慧）  [0-25]  初始: 0   ← 上限25，揭发后排除
体育老师（刘仁光）  [0-25]  初始: 0   ← 上限25，揭发后排除
学姐（沈灯织）      [0-49]  初始: 0   ← 上限49，永不锁凶
```

**三阶段**：

| 区间 | 含义 |
|------|------|
| 0–25 | 初始/排除（烟雾弹角色在此区间揭发后排除） |
| 26–49 | 重点嫌疑人 |
| 50 | 锁定凶手，进入该角色真相路线 |

### 3.3 好感度（affinity）— 按角色计

```
文穗好感度   [0-100]  初始: 70
灯织好感度   [0-100]  初始: 40
```

- 对话选择影响好感度
- 好感度≥60：角色透露"第二层"信息
- 好感度≥80：角色透露"核心秘密"
- 好感度≤20：角色隐瞒信息甚至误导

**灯织好感度阈值效果**：

| 好感度 | 灯织透露的信息 |
|--------|---------------|
| <40 | "你的小松鼠最近好像很忙。" |
| 40–60 | "她好像在躲什么人。你注意到了吗？" |
| 60–80 | "有人来找过她。不是好人。"（指侦探） |
| 80+ | "你有没有想过，问题可能不在外面？"（暗示玩家线） |

**文穗好感度阈值效果**（仅在玩家线/回忆中出现）：

| 好感度 | 文穗的行为表现（回忆/幻觉） |
|--------|--------------------------|
| ≥80 | 文穗的幻觉更温暖，会说"没关系" |
| 40–60 | 文穗的幻觉中性，沉默为主 |
| ≤20 | 文穗的幻觉冷漠/恐惧，会说"别碰我" |

### 3.4 行程还原进度（investigation）

```
行程还原进度  [0-100]  初始: 0
```

- 每发现一个文穗当天的站点 → +15–20
- 完整还原（6个站点全发现）→ 100
- 行程还原进度影响：
  - ≥30：第4轮复盘时可获得更详细的嫌疑评估
  - ≥60：解锁文穗笔记本的深层内容
  - ≥80：解锁死亡地点的详细调查
  - 100：理解文穗当天的完整动机

### 3.5 体力（stamina）

```
体力  [0-100（第4轮后120）]  初始: 100
```

- 每个站点调查消耗 5–25
- 体力归零 → 强制昏睡 1–3 小时 → 醒来时已到死亡时段
- 每轮重置为满值

### 3.6 理智（sanity）

```
理智  [0-100]  初始: 70
```

- 每轮 -5（既视感/幻觉递增）
- 发现与自身有关的线索时额外 -5–10
- 阈值效果：

| 理智区间 | 效果 |
|---------|------|
| 70–100 | 正常：LLM 文风写实、选项理性 |
| 40–69 | 不安：LLM 文风加入主观色彩、偶尔幻觉描写 |
| 20–39 | 偏执：出现异常选项（如"检查自己的手"）、幻觉频繁 |
| <20 | 崩溃：LLM 文风碎片化、可能出现"不存在的对话" |

### 3.7 已收集线索（unlockedClues）

- 字符串数组，记录所有已发现线索的 ID
- 跨轮回保留
- 每条线索带元数据：来源站点、发现轮次、关联角色

### 3.8 已见结局（endingsSeen）

- 字符串数组，记录已通关的结局 ID
- 影响二周目：解锁新的调查选项、NPC 元认知对话

## 四、线索的多重指向设计

### 设计原则

同一条线索可能指向不同角色。玩家需要通过多轮收集交叉验证才能确定指向。

### 示例：线索「请假电话是男的打的」

| 可能指向 | 理由 | 如何排除/确认 |
|---------|------|-------------|
| 玩家自己 | 玩家手机号 | 确认：查通话记录 |
| 侦探A | 赵刚打的 | 排除：通话记录不是他的号 |
| 文穗生父 | 生父打的 | 排除：生父被标为"不下场" |
| 文穗自己 | 她请的假 | 排除：门卫说是"男的" |

### 示例：线索「文穗手背的擦伤」

| 可能指向 | 理由 | 如何排除/确认 |
|---------|------|-------------|
| 便利店员 | 接触时弄的 | 排除：创可贴是她在便利店之前就需要的 |
| 侦探A | 跟踪时抓的 | 确认：如果侦探A有抓痕且面料匹配 |
| 体育老师 | 骚扰时弄的 | 部分确认：体育老师线中是性骚扰证据 |
| 爬水塔台阶 | 意外 | 基线解释：水塔台阶粗糙 |

## 五、好感度/怀疑度的交互影响

### 对话选择的影响

每次与角色对话时，选择会影响好感度和怀疑度：

**示例对话（沈灯织）**：

灯织：「你的小松鼠最近好像很忙。」

| 选项 | 好感度影响 | 怀疑度影响 | 解锁 |
|------|-----------|-----------|------|
| "你好像很关心她。" | 灯织+5 | 疑灯织+5 | 灯织的微笑表情变化 |
| "她的事不用你管。" | 灯织-5 | 疑灯织+10 | 灯织："笼子太小了。" |
| "你知不知道她最近在做什么？" | 灯织+10 | 疑灯织+5 | 灯织透露"她在躲什么人"（好感≥40） |
| "……你在等什么？" | 灯织+5 | 自疑+5 | 灯织沉默，半眯眼看你 |

### 好感度对怀疑度的调节

- 好感度≥60 的角色：玩家更容易发现指向他们的"洗白证据"（降低怀疑度）
- 好感度≤20 的角色：该角色会误导玩家，可能将怀疑引向错误方向

4. 锁凶层：A / B / C / FAKE / NONE
5. 兜底：LOOP（第7轮起）

## 七、总结：各真相线的设计意图

| 路线 | 类型 | 核心体验 | 适合玩家 |
|------|------|---------|---------|
| A-阳极献祭 | 社会派推理 | "最无害的人最危险" | 喜欢社会派、隐藏真凶反转的玩家 |
| B-失手掩盖 | 犯罪推理 | "最可疑的人确实是凶手，但原因出乎意料" | 喜欢本格推理、证据链拼图的玩家 |
| C-解离重演 | 心理惊悚 | "你以为自己在找凶手，凶手就是你" | 喜欢心理反转、 unreliable narrator 的玩家 |
| NONE-漫长的告别 | 反推理 | "没有凶手，只有没说出口的再见" | 重理解而非归罪的玩家 |
| FAKE-金蝉 | 逃亡悬疑 | "查得越深，越接近毁掉她的自由" | 横向比对证据、质疑前提的玩家 |
| CULT-阳极真神 | 宇宙恐怖 | "荒诞的迷信是真的，轮回是仪式的副产物" | 高轮回深挖 A 线的玩家 |
| PSYCH-内室 | 心理惊悚+ | "连'你杀了她'都是一层保护" | 深挖 C 线与理智系统的玩家 |
| STAY-早安·永远 | 元叙事 | "最清醒的沉沦" | 收集多结局后的玩家 |
| TRUE-九点零一分 | 元叙事·真结局 | "时间第一次前进了" | 走完一切的玩家 |

**最终目标**：锁凶层各有独立证据链，玩家的调查行为自然推向某一条；解释层奖励深挖与高轮回；元层把"玩多周目"本身变成叙事。不是随机选择，而是行为模式的逻辑结果。
