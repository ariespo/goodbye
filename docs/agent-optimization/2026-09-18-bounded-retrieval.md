# 受限历史查询与回合费用统计

## 运行行为

在原有事实门、导演、审查、写作、状态分析、程序结算之间加入可选的只读查询规划。明确要求回忆、核对、比较或寻找矛盾，并且有最近四条之外的已接受历史或至少两条已知证据时，最多额外进行一次逻辑规划。普通行动和后台预规划不调用查询规划器。

规划器仅能返回最多两条 `search_history` / `search_known_evidence` 查询。程序本地执行，每条最多三条结果，总计最多六条，最多 1600 个估算 token；上下文余量不足时继续缩减或移除结果。接口能力适配和网络重试另计，均进入请求统计。查询失败回退原流程，取消继续向上传播。

历史来源要求已提交的 narrative-turn 记录、对应 assistant 消息与知识快照。限定当前故事版本和相容路线，保留说话人、时间和轮回。查询范围不包括玩家自述、失败稿、模型推理、另一版本的正文、秘密真相和未解锁线索。当前最多扫描最近 120 条聊天消息、保留 256 条历史可见行；缺少可验证提交记录的旧导入存档会保守排除。

证据来源仅为程序投影后的 `playerKnownFacts`，不读取可首次发现的 `usableFacts`。历史结果只作回顾材料，不增加事实断言来源、NPC 知识、线索或结局权限。结果保留到行动执行后的 Writer 和正文修复上下文。

## 查看统计与配置价格

- 设置 → AI 接口：分别为主模型和独立分析模型填写每百万 token 的输入、输出、可选缓存输入价格，选择 USD 或 CNY。价格绑定接口地址及模型，更换后旧价格不再适用。
- 设置 → 高级 → 编排日志：查看每回合实际等待、首次正文返回、可游玩时间、请求次数、用量、修复和费用估算。
- 正文修复、导演修复、结构化纠正、协议修复分别统计；网络/认证重试与格式兼容重试另列。
- 后台清单、预规划计入发起它们的回合，复用时不重复计费，丢弃的预规划仍计入开销。等待时间在场景持久化及提交完成后结束，不加上后台耗时。
- 最近 20 条记录的“每成功回合”估算包含窗口内失败、取消和后台开销，分别按币种汇总。它是该窗口的总开销除以成功次数，不是每条场景的服务商账单。
- 未返回用量、未配置价格、未结算请求及旧版纯耗时记录均保留未知/不完整状态。缓存价格留空时按普通输入单价估算。中断请求可能已产生服务商费用，但没有返回用量，无法据此补出实际金额。
- 统计仅保存数值和类别，不保存提示词、响应正文、查询文本、密钥或接口地址。后台更新不会恢复已清空或被容量淘汰的记录。

## 验证记录

完整自动化回归：1684 项通过，6 项需要显式启用的测试跳过，0 失败。全量 lint 与生产构建通过。浏览器在 390px 和 320px 宽度验证了价格输入/保存、未结算费用展示、无横向溢出和 44px 关闭按钮。

自动化覆盖授权/路线/版本/泄露级别、说话人归属、执行后上下文保留、普通回合不增加调用、复杂回合不错误复用预规划、坏 JSON 回退、取消、上下文预算、结构化纠正计数、实际 HTTP 重试、SSE 用量及异常帧、后台归属、清空后的迟到结果、价格绑定及保存。

独立代码审查发现并修复了历史说话人丢失、后台请求未完成时费用完整性误报、`data: null` 等异常 SSE 帧导致中断的问题。

真实服务商小样本使用既有授权的替代路由，未改默认模型，也未修改游戏存档：

1. `gemini-3.7-flash【神秘】`：查询三次 HTTP 尝试和一次流式请求均遇到 503；四次失败均记录，费用/用量未知。
2. `gemini-3.7-flash【果汁】`：查询成功，从已接受历史中取回准确原文；服务商报告输入 161、输出 301 token。随后流式请求被限流。
3. 单独重试该路由的流式小样本仍被限流。未知用量未被填成零。

这验证了真实查询、用量读取及服务商失败记录，不构成完整剧情通关或质量对照。流式兼容和用量处理以自动化回归结果为证；本次真实流式成功路径未获验证。原始数值证据保存在本地忽略目录的 `bounded-retrieval-live-unavailable.json`、`bounded-retrieval-live-query.json`、`bounded-retrieval-live.json`，不包含凭据和正文。
