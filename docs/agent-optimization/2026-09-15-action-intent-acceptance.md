# 玩家意图一致性与合法轮回验收

## 判定规则

玩家选项的原文、起点、目标地点、行动种类与对象必须贯穿规划、程序执行和正文审查。程序决定耗时、资源、事件中断及结局优先级；现有编剧根据结算表现实际过程，现有审查要求纠正不一致。正常路径不新增模型调用。

按用户确认，体力或理智耗尽后合法回到08:00并进入下一轮属于完整轮回；它不等于覆盖到午夜的完整自然日。验收记录分别报告两者，不通过自动选择休息制造自然日覆盖。

## 用户确认的剧情接续规则

用户明确选择“跨地点也可直接接续，必须服务原目标并结算路程”。因此原行动应是必须落实的开始，不能把整个回合锁成原地对话。导演可以随后安排有依据的核查或调查；所有新增路程与工作先列入计划、再按程序结算。现有正文审查判断因果联系与实际落实情况，不增加常规模型调用。

实现同时保留显式玩家限制、原事实授权和中断优先级。逐段场景契约覆盖原地点与后续地点；抵达不等于已完成接待或调查，续作不得重播已完成的路程。新地点案件事实不会仅因抵达自动取得授权。
