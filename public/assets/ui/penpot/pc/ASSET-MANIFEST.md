# Penpot PC UI Assets

All icons use a 24 × 24 integer-coordinate viewBox, `shape-rendering="crispEdges"`, and `currentColor` for black/white inversion.

Top bar: `icon-menu`, `icon-time`, `icon-location`, `icon-stamina`, `icon-sanity`, `icon-loop`.

Operation wheel: `icon-observe`, `icon-investigate`, `icon-action`, `icon-clue`, `icon-map`, `icon-operation-iris`.

Dialogue and playback: `icon-dialogue-next`, `icon-pause`, `icon-fast-forward`.

Font: `RenOuFangSong 16 / 人偶仿宋`.
